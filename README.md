# Matlab exercises

This repository contains a collection of Matlab exercises likely related to signal processing and systems. It includes both `.m` files (Matlab scripts), `.mat` files (Matlab data files) and `.fig` files (Matlab figures). These exercises appear to be structured around two main assignments each exploring various concepts and techniques in signal analysis.

## Features

*   **Organized Structure:** Exercises are grouped into folders for easy navigation.
*   **Diverse File Types:** Includes scripts, data and figures providing a comprehensive learning resource.
*   **Practical Examples:** Offers hands-on examples for understanding Matlab-based signal processing.

## Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/panoschron97/Matlab_exercises.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd Matlab_exercises
    ```

## Usage

To run the exercises:

1.  Open Matlab.
2.  Navigate to the desired exercise directory within Matlab.
3.  Execute the `.m` scripts by typing their names in the command window and pressing Enter.

    For example, to run `ask1.m` in the `1η Ασκηση Σήματα Συστήματα/askisi1` directory:

    ```matlab
    cd '1η Ασκηση Σήματα Συστήματα/askisi1'
    ask1
    ```

## Dependencies

*   **MATLAB:** This project requires MATLAB to run the scripts and open the data files.
